# Value Generator icon

Original artwork generated with the built-in image generation tool on 2026-10-27.
`ValueGenerator.png` is the transparent, high-resolution master, excluded from the
MSIX. Run `build/Generate-Assets.ps1` from the repository to derive package sizes.

Visual brief: a single hash (#) symbol for a developer utility, inspired by Fluent
Windows app icons; rounded interwoven bands, restrained blue/cyan gradients,
subtle dimensional depth, centered composition and transparent background. No
text, surrounding tile, Microsoft logo or PowerToys logo. Preserve recognizability
at small sizes.

Reference: https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-design
